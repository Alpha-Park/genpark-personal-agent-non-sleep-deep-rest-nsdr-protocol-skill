# Personal Agent Non-Sleep Deep Rest (NSDR) Protocol Skill

Designed for **OpenClaw**, **Hermes**, and sovereign personal AI assistants to evaluate acute autonomic de-escalation, track respiratory deceleration, quantify theta-wave hypnagogic entrainment, and model striatal dopamine replenishment.

## Agent In-Context Capabilities

- **Parasympathetic Down-Regulation Index (PDRI)**: Combines respiratory deceleration and subjective arousal drop into a unified restorative metric.
- **Striatal Dopamine Tracking**: Employs PET imaging benchmarks (Kjaer et al., 2002) indicating up to +65% striatal dopamine restoration without slow-wave sleep inertia.
- **Circadian Rest Scheduling**: Prescribes 10-30 min windows timed to blunt postprandial somnolence without cannibalizing nighttime sleep debt.

## Tools Summary

1. `evaluate_nsdr_state_shift`: Computes PDRI, respiratory deceleration percentage, and estimated dopaminergic replenishment.
2. `recommend_nsdr_timing_protocol`: Schedules duration and execution protocol based on sleep debt and cognitive strain.
